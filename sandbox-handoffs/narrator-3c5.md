# narrator-3c5 — pyproject.toml missing networkx dependency

## What was wrong

`motive.py` and `mystery.py` both `import networkx as nx`, but
`pyproject.toml` declared `dependencies = []`. From a clean environment,
`uv sync` installed nothing for networkx, so `uv run python mystery.py` /
`uv run python motive.py` failed with `ModuleNotFoundError: No module named
'networkx'`. Reproduced before making any change:

```
$ uv run python -c "import networkx"
...
ModuleNotFoundError: No module named 'networkx'
```

## Fix

Added the missing runtime dependency:

```diff
-dependencies = []
+dependencies = ["networkx>=3"]
```

Ran `uv sync`, which resolved and installed `networkx==3.6.1` and wrote the
lockfile update (`uv.lock`).
